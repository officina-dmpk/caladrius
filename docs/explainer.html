Caladrius and Apothicaire, explained

A guided tour in plain words. Caladrius is a calculation engine for pharmacokinetics. Apothicaire is a local AI assistant that uses it and is not allowed to calculate. This page is self-contained: it loads nothing from the network.

1. One picture 2. What is measured 3. How the engine is checked 4. An AI that may not calculate 5. The benchmark 6. How it is built 7. Words

1. The project in one picture

A person asks a question about a drug concentration profile. The AI reads the question and the data. It decides which calculation is needed and asks Caladrius to run it. Caladrius returns numbers with units. The AI explains them. A deterministic check then reads the answer and rejects any number that did not come from Caladrius or from the person.

Two kinds of boxes matter. The dashed box is a language model: it can misread, invent or round. The solid blue boxes are ordinary programs with tests: given the same input they always give the same output. The design puts the one unreliable part between reliable ones.

2. What is measured: a concentration curve and four numbers

After a dose, the concentration of a drug in blood rises, peaks and falls. Pharmacokinetics turns that curve into a few numbers. Move the sliders. The curve below is a toy drawn by this page for illustration only; in the real tools every number comes from the Caladrius engine, never from a page or from an AI.

Cmax, the peak
Tmax, when the peak happens
AUC, the shaded area
Clearance, dose over AUC

Cmax and Tmax are read from the points: the highest measured concentration and its time. AUC, the area under the curve, is the total exposure; it is built from trapezoids between the measured points, then extended to infinity with the slope of the tail. The slope of the tail is found by fitting a straight line to the last points of the semi-log view; it gives the half-life. Clearance, the volume of blood cleaned per hour, is the dose divided by the AUC. Each of these has rules: which points enter the tail, what to do with a value below the detection limit, which trapezoid rule to use. Caladrius writes down every such rule in specs/, with its source and a status.

This is called non-compartmental analysis (NCA): no model of the body, only arithmetic on the data. The other half of Caladrius fits compartmental models, where the body is one or two tanks with pipes, and the parameters of the tanks are found by least squares.

3. How the engine is checked

"Verified" has one narrow meaning in this project: a number produced by Caladrius equals a number produced by an independent program, within a stated tolerance, on a stated case. The independent numbers are called the oracle. They are produced by scripts that anyone can rerun, and the comparison is a command that regenerates a table and fails if any count goes down.

The time the oracle was wrong

On nine fits with a particular weighting, the engine and the first R script disagreed. The easy move is to widen the tolerance until the test passes. The project instead wrote the disagreement down as a documented difference and investigated. The engine's points were checked by hand and upheld; the R script had accepted degenerate solutions. The script was corrected, its cases regenerated, and a second, naive re-computation of every statistic was added so that the same class of error would be caught next time. The lesson stated in the README: the oracle is not infallible, and a tolerance is never loosened to hide a disagreement.

4. An AI that is not allowed to calculate

Apothicaire runs a 27-billion-parameter language model on one 12 GB graphics card. The model is good at reading a question and choosing a tool. It is bad at arithmetic, unit conversion and copying long numbers. So the rule is simple: it may never write a pharmacokinetic number that it did not receive. Press Next to follow one question through the system.

Person
Compare the AUC of my two analyses: by how much do they differ, in value and in percent?
Language model, thinking
Two analyses exist (linear and lin-up/log-down). I must not subtract myself. Call the engine's compare tool.

The two AUC are 76985 and 76102 ng·h/mL. The difference is 883 ng·h/mL, that is 1.16 %.
Number gate, deterministic

1.16    not found in any tool result or user message  reject
(the model did the subtraction itself: 883 is right by luck, 1.16 is rounded wrongly)
→ regenerate once with the list of rejected numbers
Language model, with the compare tool (the afternoon run)
Linear 76985 ng·h/mL, lin-up/log-down 76102 ng·h/mL: difference -883.0 ng·h/mL, -1.147 % (engine values).
Number gate
76985, 76102, -883.0, -1.147   all found in tool results  pass

The gate is a short Python program. It extracts every number from the answer and looks for it, as a string with a small rounding allowance, in the tool results and in the person's messages. It knows nothing about pharmacokinetics. That is the point: a check that cannot be argued with. What the gate cannot see is a right number quoted for the wrong parameter; a second, separate check reads the label before each number and compares with the engine's value for that label.

5. The benchmark, in numbers

Caladrius simulated 25 exercises (different routes, units, two with values below the detection limit). Each exercise is a scripted conversation of 8 questions in French, 200 turns in all. The same run was done twice on 9 October 2026: once with six tools, once after the engine gained a compare command exposed as a seventh tool.

The second check's label table was adjusted after reading the answers, so its figure is not out-of-sample. The remaining failures are listed one by one in the Apothicaire README. The next step is a fresh set of exercises that the scoring rules have never seen.

6. How it is built

By AI agents, under a contract. The code is written by coding agents (Claude Code, with a DeepSeek agent as a second contributor). They work from a written contract, AGENTS.md, and a task board. The human answers questions, reviews, and decides what is published. The contract's main rules: reproduce behaviour from textbooks and public documentation, never from the commercial software's code (clean room); no change without a test; the conformance counts can only go up; never crash on bad input.

In Rust. Not for speed. The compiler forces every "this value may be missing" case to be handled where it occurs, the linter forbids the patterns that crash, and the result is one file with no runtime to install, on Windows, Linux and a Mac, and in a browser through WebAssembly. The layer rules (numerical code may not depend on the interface; the interface holds no numerical code) are checked by a command in the continuous integration.

Every analysis is a command. The desktop window, the command line and the AI all call the same command with the same parameters and get the same result. Nothing is computed twice in two places.

With a memory that forgets nothing. OptChat, an idea by Victor Taelin: the whole conversation stays on disk; the model sees recent messages verbatim and older ones merged into summary lines, arranged as a tree, so a long session fits in a bounded context.

7. Words

DMPK
Drug metabolism and pharmacokinetics: what the body does to a drug.
NCA
Non-compartmental analysis: parameters computed from the measured points without a model of the body.
AUC
Area under the concentration-time curve: total exposure.
λz, half-life
The slope of the terminal part of the curve on a log scale, and the time for the concentration to halve.
Clearance
The volume of blood cleaned of the drug per unit of time; dose divided by AUC.
Compartment
A tank in a simplified model of the body; one or two tanks with pipes between them.
Fit, weighted least squares
Finding the model parameters that bring the curve closest to the points, giving some points more weight.
Oracle
An independent program that produces the expected values the engine is compared with.
Tolerance
The largest relative difference still counted as agreement, stated once per kind of calculation.
Conformance table
The regenerated list of how many expected values the engine matches, per case; it can only improve.
MCP
Model Context Protocol: an open way for an AI to call tools; Caladrius exposes every command through it.
Number gate
The deterministic check that rejects any number in an answer not found in a tool result or in the person's message.
Ternary model
A language model whose weights take three values, so a 27-billion-parameter model fits in a few gigabytes.
Clean room
Reproducing behaviour from public sources without ever looking at the original program's code.

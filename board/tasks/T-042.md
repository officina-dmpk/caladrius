# T-042: `analysis.compare` command: differences and ratios between two analyses, computed by the engine

- **Role:** interface
- **State:** todo
- **Depends on:** T-034

## Goal

The Apothicaire benchmark of 2026-10-09 (`../agent/bench/runs/2026-10-09/report.md`) found that all 76 unverified numbers of the first drafts come from the one turn that asks to compare two AUC values: the model subtracts or divides by itself. The rule "the model never computes" needs a command that does the arithmetic for it (agent/README problem 3; both external reviews).

1. New engine command `analysis.compare` (stable id, serde parameters, schema): inputs are two analysis ids of the same project (NCA or fit results) and an optional list of parameter names (default: every parameter present in both); output: for each parameter present in both results, the two values with their units, the absolute difference (b − a) with its unit, the relative difference (b − a)/a as a percentage, the ratio b/a, and a `not_comparable` reason when units differ, a value is not available, or a is zero. Numbers are computed in `caladrius-engine` or lower (never in the UI), with the same formatting rules as the other results (no rounding beyond what the result types already do). Units: reuse the unit strings of the results; if they differ, no number, a reason.
2. Also accept comparing one analysis with itself re-run under other options? No: out of scope; two ids only.
3. Exposed through the CLI (`compare` subcommand, table output like `export_table`) and the MCP server (`analysis_compare` tool, description in one line, schema small: the MCP `tools/list` growth must stay under 600 bytes).
4. The UI: not in this card (a later slice may show a comparison table).
5. Tests: engine tests on two NCA analyses of the same worksheet with different AUC methods (the benchmark's compare turn), on an NCA and a fit (parameters in common, e.g. half-life), on unit mismatch, on a missing value, on a = 0; CLI and MCP tests that the command runs; a test that the schema is under the size limit.
6. `../agent` follow-up (not this card): expose the tool in the Apothicaire client and re-run the compare turn of the benchmark.

## Allowed files

`crates/caladrius-engine/`, `apps/caladrius-cli/`, `apps/caladrius-mcp/`, `README.md` (one line in the CLI/MCP commands list), the card. Not the numerical crates, not `caladrius-ui`.

# T-014: documented differences in the oracle (negative concentrations)

- **Role:** oracle
- **State:** to review
- **Depends on:** T-012

## Goal

PKNCA takes a trailing negative concentration as Clast/Tlast; Caladrius never does (spec NCA-DAT rules). Add a "documented difference" mechanism: the `.options.json` of a case may list parameters whose expected value is known to differ, with a difference id (`D-01`); the testkit comparison skips them and reports them separately; `cargo xtask conformance` counts them in a "documented differences" column, not as failures and not as validated. Write `specs/differences.md` entry D-01 (what PKNCA does, what Caladrius does, why, the case and parameters affected). Apply it to the 5 `edge_negative_*` expectations.

## Allowed files

`oracle/`, `crates/caladrius-testkit/`, `crates/caladrius-nca/tests/`, `xtask/src/conformance.rs`, `specs/differences.md` (create or append), `board/QUESTIONS.md` (append).

## Completion criterion

```sh
cargo test -p caladrius-testkit -p xtask       # ok, with tests for the new marker
cargo xtask conformance                        # edge_negative_* shows 5 documented differences, no failure for them
```

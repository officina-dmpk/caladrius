# T-010: caladrius-models

- **Role:** engine
- **State:** to review
- **Depends on:** T-008, T-009

## Goal

Closed-form one-compartment models (bolus, infusion, first-order absorption with tlag, zero-order absorption) as data-driven model definitions: a `Model` enum/struct with parameterisation, a `predict(params, times) -> Vec<f64>` and analytical partial derivatives where the spec gives them (otherwise a documented finite-difference fallback), secondary parameters, serde, readable errors (negative parameters, zero volume, infusion duration ≤ 0). 100% of the models oracle.

## Allowed files

`crates/caladrius-models/src/`, `crates/caladrius-models/Cargo.toml`, `specs/differences.md` (append).

## Completion criterion

`cargo test -p caladrius-models` all green incl. oracle tests; clippy clean; `cargo xtask layers`; `cargo xtask conformance` extended by the oracle agent or here (orchestrator decides) to include model cases. Reviewer approval.

  - Numerics (MOD-AB1-03, NUM-01), all exact rewritings of the spec's closed forms, no positive exponent and no difference of nearly equal terms: first-order input written symmetrically in k and ka with a = min(k, ka), δ = |ka − k|: C = (D/V)·ka·s·e^(−as)·g(δs), g(z) = −expm1(−z)/z; AUC(0, s) = (D/CL)·[q(as) + as·e^(−as)·(1 − g(δs))] with q(y) = 1 − e^(−y)(1 + y) and 1 − g(z) by their alternating series below 0.1 (both terms positive, so no cancellation for any ka/k, including ka = k). Zero-order/infusion: C = (D/(T·CL))·(−expm1(−ks)), AUC during = (D/(T·CL))·s·(1 − g(ks)), after = AUC(T) + C(T)·(−expm1(−k(s − T)))/k. Bolus AUC = (D/CL)·(−expm1(−kt)). Tmax first-order = ln_1p((ka − k)/k)/(ka − k) (1/k when equal); Cmax = (D/V)·e^(−k·Tmax). These are the spec's formulas rearranged, not other answers, so no entry in `specs/differences.md`.
  - For the reader (spec fix, not mine to edit): worked example M5 prints C(5) = 3.6787944006 for ka = k + 1e-9; the exact value (oracle T-009 and this engine) is 3.6787944209. The unit test uses the exact value.
  - Derivatives: `jacobian(input, Derivatives)`: forward differences with a relative increment (FIT-JAC-01, `DEFAULT_INCREMENT` 0.001), analytic for the IV bolus (FIT-JAC-02, both (V, k) and (V, CL) parameterisations); `Analytic` on other models falls back to forward differences and reports the method used (the spec gives no other closed-form derivatives).

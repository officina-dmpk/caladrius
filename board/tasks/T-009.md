# T-009: Oracle for models and fitting

- **Role:** oracle
- **State:** done
- **Depends on:** T-008

## Goal

Ground truth for step 3. Models: exact closed-form values on a grid for each model and parameterisation, computed by an independent R script (own formulas, cross-checked against rxode2 or mrgsolve simulations within 1e-8). Fitting: weighted least-squares reference fits computed in R with `nls` (and `minpack.lm::nlsLM` as a second optimizer) on theophylline (oral one-compartment with first-order absorption, per subject) and indomethacin (IV bolus), each weighting scheme, with the full output set (parameter estimates, SE, CV%, residual SS, AIC) written to `oracle/expected/fit_*.csv`; textbook worked examples with page references where allowed. Tests in `crates/caladrius-models/tests/` and `crates/caladrius-fit/tests/` that fail first, against an API specified in the card for the engine.

## Allowed files

`oracle/`, `crates/caladrius-testkit/`, `crates/caladrius-models/tests/`, `crates/caladrius-fit/tests/`, `ATTRIBUTION.md` (append), `board/QUESTIONS.md` (append).

## Completion criterion

Scripts regenerate byte-identical expected files; `cargo test -p caladrius-testkit` ok; the new tests fail (no engine yet); expected value counts reported.

  - **(d) The `abs: 1e-12` question: decided and changed.** The floor was added to every comparison (`rel * |e| + abs`), so for an expected value below about 1e-6 it silently dominated the relative tolerance (a 1e-5 relative error passes at 1e-7; anything passes at 1e-14). If a future parameter is a difference that cancels to noise (a percent extrapolated near 0), handle it by a documented difference or a per-parameter rule, not by a global floor.

# T-001: Cargo workspace skeleton, xtask layers/wasm, lints

- **Role:** interface
- **State:** to review
- **Depends on:** T-000

## Goal

Create the Cargo workspace described in `AGENTS.md` section 4, with every crate empty but compiling, the deny lints of golden rule 6 in every crate, and the `xtask` commands `layers` and `wasm`.

## Allowed files

`Cargo.toml` (workspace root), `rust-toolchain.toml`, `.cargo/config.toml` (optional), `crates/*/`, `apps/*/`, `xtask/`, `.gitignore` (append only), `README.md` (append a "Build" section only).

## Specification

1. Workspace members: `crates/caladrius-nca`, `crates/caladrius-models`, `crates/caladrius-fit`, `crates/caladrius-project`, `crates/caladrius-engine`, `crates/caladrius-ui`, `crates/caladrius-testkit`, `apps/caladrius`, `apps/caladrius-cli`, `apps/caladrius-mcp`, `xtask`. Edition 2024, `resolver = "3"`, license `MIT OR Apache-2.0`, shared `[workspace.package]` and `[workspace.lints]`.
2. Each library crate: `src/lib.rs` starting with `#![deny(clippy::unwrap_used, clippy::expect_used, clippy::panic, clippy::todo, clippy::unreachable)]` (or the equivalent workspace lint table), a one-line crate doc comment naming its layer, no dependencies yet except where unavoidable. Do not add egui, eframe, wgpu or winit to anything yet; `caladrius-ui` and `apps/caladrius` are empty placeholders for now (no UI framework dependency until step 5).
3. `xtask layers`: reads every crate's `Cargo.toml`, knows the layer table (nca, models, fit = L0; project = L1; engine = L2; ui = L3; testkit = test; apps = app), fails if a crate depends on a crate of a higher layer, or if anything below `caladrius-ui` depends on egui/eframe/winit, or if a workspace crate is missing from its table. Exit code 1 on violation with a readable message.
4. `xtask wasm`: runs `cargo check --target wasm32-unknown-unknown` on L0 to L3 crates; installs nothing itself. If the target is missing it prints the `rustup target add wasm32-unknown-unknown` command and exits 1. (Installing the target with rustup is allowed: do it.)
5. `.cargo/config.toml` with `[alias] xtask = "run --quiet --package xtask --"`.
6. `.gitignore` must contain `/target`, `/target-*`, `/private/`.

## Completion criterion

```sh
cargo build --workspace            # ok, no warnings
cargo clippy --workspace --all-targets -- -D warnings   # ok
cargo xtask layers                 # prints the layer table, exit 0
cargo xtask wasm                   # exit 0 (target installed) for L0-L3
```

and a deliberate violation (temporarily adding `caladrius-engine` as a dependency of `caladrius-nca`) makes `cargo xtask layers` exit 1; revert it before committing.

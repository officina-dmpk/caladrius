# T-024: caladrius-ui, first screen: worksheet and NCA with λz point selection

- **Role:** interface
- **State:** to review
- **Depends on:** T-022, T-017 (specs/ux.md)

## Goal

Step 5, first slice. `crates/caladrius-ui` (egui, eframe on wgpu for the desktop app `apps/caladrius`; L3 must stay wasm-clean: no file IO in the crate, the app passes bytes) driven only through `caladrius-engine` commands: (1) a theme token file (light and dark; colours, radii, spacing as data, `specs/ux.md` rules); (2) the project tree, a worksheet view (import CSV via a file picker in the app layer, preview before import with the locale/separator detection of friction 10, cell editing through `data.set_cell`); (3) one NCA page read top to bottom (data, dose and route, options, results) with the plot always visible: semi-log toggle that never fails on zeros (friction 9), the terminal-phase points selectable by clicking on the curve (manual λz selection through the engine option), results summary first (parameters with flags, λz window, %extrapolated) and details on demand; (4) stale results shown clearly after an input change; (5) the offscreen snapshot example `cargo run -p caladrius-ui --example snapshot` writing PNGs of each screen that you look at before delivery (golden rule 8). Keep the UI thin: no numeric code, no parsing outside the engine.

## Allowed files

`crates/caladrius-ui/`, `apps/caladrius/`, `Cargo.toml`, `Cargo.lock`, `ATTRIBUTION.md` (append: egui/eframe/wgpu and any font, with licenses), `README.md` (Desktop section).

## Completion criterion

```sh
cargo test -p caladrius-ui
cargo clippy -p caladrius-ui -p caladrius --all-targets -- -D warnings
cargo xtask layers && cargo xtask wasm      # ui compiles for wasm32 (eframe web feature), app excluded
cargo run -p caladrius-ui --example snapshot # PNGs under target/snapshots, listed in the card
cargo run -p caladrius -- --help            # app starts headless-free
```

Then `reviewer` approval (UI review: panic paths on user input, engine-only data path, theme tokens, no hard-coded colours).

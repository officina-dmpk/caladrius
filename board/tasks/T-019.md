# T-019: private oracle infrastructure and exercise 1 (NCA)

- **Role:** oracle
- **State:** in progress
- **Depends on:** T-013

## Goal

The private oracle of `AGENTS.md` section 5.2, behind the Cargo feature `private-oracle`: tests that read `private/exports/<td>/` and `private/coursework/` and are skipped (not failed) when the folder is empty; a loader for the reference software's exported tables (format to be discovered from the first export the human drops in `private/exports/td1/`: expect CSV tables named like "Final Parameters" and "Summary", one row per parameter or a wide row per profile; make the loader tolerant to both and to the decimal separator); the comparison rule "equality at the precision displayed in the export" from section 5; a `cargo xtask conformance --private` mode (or automatic inclusion when the folder exists) that reports private cases separately and never writes a private number into `docs/conformance.md` (counts only). First case: exercise 1 (10 mg oral, data in `private/coursework/td1_exercice1_oral.csv`), two AUC methods (linear trapezoid with linear interpolation; linear-up/log-down), with the reference software's defaults (uniform λz weighting, no acceptance thresholds, see Q-008 observations in `board/QUESTIONS.md`). Until the exports arrive, build everything against a placeholder format and leave the comparison test skipped with a clear message; when they arrive, finish and report the conformance.

## Allowed files

`crates/caladrius-testkit/`, `crates/caladrius-nca/tests/oracle_private.rs` (new), `crates/caladrius-nca/Cargo.toml` (feature only), `xtask/src/conformance.rs`, `oracle/README.md` (append), `board/QUESTIONS.md` (append). Never copy a number, file or name from `private/` into a versioned file, a commit message or the board.

## Completion criterion

```sh
cargo test -p caladrius-nca --features private-oracle   # skipped with a message when private/ is empty; runs when exports exist
cargo xtask conformance                                 # public unchanged; private counts reported only when present
```

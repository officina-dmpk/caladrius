# T-013: caladrius-nca: edge-case parameters and the PKNCA profile for replaced values

- **Role:** engine
- **State:** to review
- **Depends on:** T-012

## Goal

Make `crates/caladrius-nca/tests/oracle_edge.rs` green except the five `edge_negative_*` expectations that T-014 will mark as documented differences. (1) Missing parameters: `tlag`, plain `vss.obs` and `vss.pred`, `vss.iv.last`, `aumcall.dn`, the `auciv*` family (`aucivlast`, `aucivall`, `aucivinf.obs/pred` and `aucivpbext*`) as defined in `specs/nca.md` and shown by the oracle cases `edge_oral`, `edge_iv*`, `edge_infusion*`. (2) Replaced values (`edge_blq_set`, `edge_missing_replace`): a zero or missing concentration replaced by a number is an ordinary point for the areas and the λz candidate set, and `auclast` runs to the last positive point after replacement; `tfirst`, `tlast`, `clast.obs` are taken from the data before replacement. Keep the previous exclusion behaviour behind a new boolean field of `NcaOptions::lambda_z_selection` (default off), with a test. (3) Leave the negative-value rule as the spec says (a negative concentration is never Tlast/Clast).

## Allowed files

`crates/caladrius-nca/src/`, `crates/caladrius-nca/Cargo.toml`, `specs/differences.md` (append only).

## Completion criterion

```sh
cargo test -p caladrius-nca --no-fail-fast     # oracle_edge: only the 5 edge_negative documented-difference tests may fail (until T-014 marks them); everything else green
cargo clippy -p caladrius-nca --all-targets -- -D warnings
cargo xtask conformance                        # public cases 100%, edge cases: report the new percentage
```

Then `reviewer` approval.

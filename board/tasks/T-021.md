# T-021: caladrius-cli

- **Role:** interface
- **State:** done
- **Depends on:** T-020

## Goal

`apps/caladrius-cli`: `caladrius-cli <command-id> [--param value | --json file]` and `caladrius-cli commands` (lists ids and schemas), reading a CSV worksheet and printing result tables (CSV or JSON, `--format`), exit code 1 with a readable error on any failure; a `run` of the NCA on `oracle/data/theoph.csv` must reproduce the oracle (add an integration test that runs the binary). Also `cargo xtask conformance` extended to model and fit cases (per-parameter floors, same rules) so the conformance table covers steps 2 and 3.

## Allowed files

`apps/caladrius-cli/`, `xtask/src/conformance.rs`, `docs/conformance.md` (generated), `README.md` (Usage section only).

## Completion criterion

`cargo test -p caladrius-cli -p xtask`; clippy; `cargo xtask conformance` includes models and fit at 100%; a documented example in README. Reviewer approval.

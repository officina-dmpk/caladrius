# T-003: Public NCA oracle with PKNCA, testkit tolerances, failing tests

- **Role:** oracle
- **State:** to review
- **Depends on:** T-001

## Goal

Ground truth for NCA: public datasets, expected results computed by a versioned R script with `PKNCA`, the comparison helpers and tolerances in `caladrius-testkit`, and tests in `caladrius-nca` that fail because the implementation does not exist yet.

## Allowed files

`oracle/`, `crates/caladrius-testkit/`, `crates/caladrius-nca/tests/` (tests only, no `src/`), `ATTRIBUTION.md` (append only), `board/QUESTIONS.md` (append only).

## Specification

1. Datasets: theophylline (`Theoph`) and indomethacin (`Indometh`) from R's `datasets` package, exported to CSV in `oracle/data/` with a `README.md` giving origin and license; one textbook worked example per administration route if page references can be given without copying text.
2. `oracle/scripts/nca_pknca.R`: computes, per subject, the full in-scope parameter set with PKNCA, with the options written explicitly (AUC method, λz selection rule, BLQ handling), and writes `oracle/expected/<dataset>.csv` plus `oracle/expected/<dataset>.options.json`. Record the PKNCA and R versions in the output.
3. `caladrius-testkit`: `Tolerance` type with the values from `AGENTS.md` section 5 (NCA vs PKNCA: relative error ≤ 1e-6), a table comparison helper that reports every parameter outside tolerance (never stops at the first), and loaders for `oracle/`.
4. Tests in `crates/caladrius-nca/tests/oracle_public.rs`: one test per dataset and parameter group, calling a public API you define in the test (`caladrius_nca::run(...)` with a documented input type); they must compile only once the engine provides that API, so write them against the API described in `specs/nca.md` and leave them failing (not ignored). If the API is not yet specified, write the expected signature in the task card for the engine agent.

## Completion criterion

```sh
Rscript oracle/scripts/nca_pknca.R            # regenerates oracle/expected/*.csv identically
cargo test -p caladrius-testkit               # ok
cargo test -p caladrius-nca                   # fails to compile or fails: expected at this step
```

Report the number of expected values per dataset.

  - **Facts the engine must know (found while building the oracle):**
    1. Indometh has no sample at t=0. PKNCA refuses AUC from 0 unless a t=0 point exists, so the script adds C0 (log back-extrapolation from the first two points, `pk.calc.c0` method `logslope`) as a profile point; `cmax/tmax/tfirst` are taken from observed samples only, and the added point plus the observed Cmax are excluded from the terminal-phase selection (otherwise subject 4 picks a different window); the script asserts lambda.z is identical with and without the added point.
    2. `tfirst` is the first time with a positive concentration (Theoph subjects with conc 0 at t=0 have tfirst > 0). Found by the independent cross-check in testkit.
    3. `min.hl.r.squared = 0.9` does not blank lambda.z: Indometh subject 4 has R squared 0.867 and a lambda.z. The engine must not apply an R squared floor by default.
    4. Indometh terminal windows are wide (3 to 10 points) because the profile is biexponential; they are a good test of the best-adjusted-R-squared rule.
    5. `aucpext.*` is a percentage; `cl.*` = dose/AUCinf; `vz.*` = cl/lambda.z; oral `mrt.obs` = AUMCinf/AUCinf (no MAT correction); IV `mrt.iv.*`, `vss.iv.*` = cl * mrt.
    6. Theoph dose = Dose (mg/kg) * Wt (kg). Indometh dose 25 mg is a test constant (R's documentation gives none); only CL/Vz/Vss scale with it. Stated in `oracle/data/README.md`.

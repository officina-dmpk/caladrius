## Goal

Decided by the human on 2026-10-09 after two independent reviews (`../notes/review-fable-2026-10-08.md`, `../notes/review-deepseek-2026-10-08.md`). Both found that "100% conformance on 9970 values" oversells: NCA is validated against PKNCA 0.12.1 and synthetic cases, models against closed forms, fits against R `nls`/`nlsLM` but only for `pk1.iv_bolus` and `pk1.oral_1` (15 cases = 3 datasets x 5 weightings); infusion, zero-order and lag models have no fit oracle; the 1e-4 fit tolerance reads as "tuned until it passed"; D-02 shows an oracle regenerated after a disagreement (rightly, but it must be told).

Say that D-02 was found by disagreement and how it was settled (T-018). Say which spec rules are `assumed` versus `confirmed` (counts from `specs/*.md`).
2. **Tolerance note** in `specs/fit.md` (or `specs/differences.md`) and summarised in the README: why fit parameters use 1e-4 relative (different optimizer, finite-difference derivatives, stopping rule) while NCA uses 1e-6, with one hand-checked fit case where Caladrius and the R reference agree at 1e-6, to show the looser tolerance is caution, not cushion. Add that case as a test at 1e-6 in `caladrius-testkit`/oracle tests (do not loosen anything).
3. **Missing fit oracles**, written with the versioned R script (nls + nlsLM, same datasets or synthetic profiles from `caladrius-models` closed forms with noise, seed fixed): `pk1.iv_infusion`, `pk1.zero_order` (zero-order input), `pk1.oral_1_lag` (first-order with lag), each with the five weightings; expected values in `oracle/expected/`, tests in the engine test suite that fail first if the engine disagrees. Report in the card how many of the new fit tests pass; do not fix the engine (an engine card follows if needed).
4. Regenerate `docs/conformance.md` with `cargo xtask conformance` and commit it.

- **Role:** interface
- **State:** done
- **Depends on:** T-040

## Goal

T-040 made the exact minimum the default fit setting and kept the assumed reference defaults as the preset `reference_conventions` (engine schema `preset` enum, `derivatives` value `auto`). The preset is reachable from the CLI, MCP and project files but not from the desktop UI (reviewer note c of T-040). Add it to the fit page:

1. In "More options" of the fit page, a `Preset` choice (`Caladrius default`, `Reference conventions`) with one sentence under it saying what each means (default: closed-form derivatives when available, relative decrease 1e-10; reference conventions: forward differences with increment 1e-3, convergence 1e-4; both 50 iterations), the values read from the engine (`FitOptions::preset()` through the command or schema), never duplicated in the UI.
2. Choosing a preset fills the option fields (derivatives, increment, convergence, iterations) and the fields stay editable; editing a field after a preset shows "custom" as the preset label. The stored analysis records the explicit values (as today), so an old project file still opens.
3. The simulation page is unaffected. The palette gets no new entry.
4. Tests: choosing each preset yields exactly the engine's values; editing after a preset shows custom; a stored fit with explicit values reopens with the right label. Snapshot of "More options" with the preset shown, light and dark, looked at before delivery and listed in the card.

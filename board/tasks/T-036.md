# T-036: `cargo xtask lint`: clean-room and contract checks as a deterministic gate

- **Role:** interface
- **State:** done
- **Depends on:** T-028

## Goal

Both reviews of 2026-10-08 and the agentlint idea (rules as deterministic gates with recorded acceptances) point the same way: the contract rules that are mechanical should be checked by a command, not by memory. Add `cargo xtask lint` (and run it in CI after `xtask layers`):

1. **Forbidden names** (AGENTS.md top): "Phoenix", "WinNonlin", "Certara" anywhere in versioned files except the README trademark notice and `specs/sources.md` legal-notice lines (allow-list by file and line pattern, kept in `xtask/lint_allow.toml` with a reason per entry).
2. **No `private/` content leaks:** no versioned file (outside `private/`, which is git-ignored anyway) contains a path under `private/` other than the documented ones (AGENTS.md, README, the private-oracle loader code, the board cards that say "private"); and no versioned file contains a number listed in a small hidden-values file... no: that would store the numbers. Instead: the rule is "no CSV, RTF or XLS under private/ is referenced by name", plus a check that `git ls-files` contains nothing under `private/`.
3. **Deny-lints header** present in every crate root (`#![deny(clippy::unwrap_used, ...)]` as in AGENTS.md golden rule 6), with the exact list.
4. **Tolerances defined once:** no numeric literal tolerance in `assert!`/`assert_relative`-like calls inside `tests/` of the numerical crates outside `caladrius-testkit` (heuristic: regex on `1e-` literals in `crates/*/tests/*.rs` except through testkit constants; allow-list with reasons for the property tests noted in T-032).
5. **Board hygiene:** every `board/tasks/T-*.md` has a `State:` among the five allowed states and is listed in `board/INDEX.md` with the same state; LOG entries start with a date.
6. **English only** in versioned files is not checkable mechanically; skip it.

Output: one line per finding with file:line and the rule id; exit 1 on any finding; `--fix` not needed. Tests for every rule on fixtures (a positive and a negative case each) under `xtask/tests/` or in the module. Keep it fast (whole repo in under 2 s).

## Allowed files

`xtask/`, `.github/workflows/ci.yml` (add the step), `README.md` (one line in the development section), the card. If the lint finds real violations in the current tree, do not fix them silently: list them in the card thread for the orchestrator (except trivial ones in your own allowed files).

## Completion criterion

```sh
cargo xtask lint          # exit 0 on the current tree, or the findings listed in the card
cargo test -p xtask
cargo clippy -p xtask --all-targets -- -D warnings
```

Orchestrator reads the diff. Absolute `CARGO_TARGET_DIR` under `target/agent-interface`.

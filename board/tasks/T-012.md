# T-012: Oracle edge cases without public coverage

- **Role:** oracle
- **State:** in progress
- **Depends on:** T-007

## Goal

`specs/nca.md` open item O-17 lists rules implemented by the engine but not exercised by the public oracle: interior zero / BLQ concentrations (BLQ policies), missing and negative values, IV infusion route (MRT correction), Tlag, percent back-extrapolated, MRTlast, dose-normalised values, AUMC percent extrapolated, plain `vss.obs`. Build small synthetic profiles (one per rule, documented in `oracle/data/README.md`), run PKNCA with explicit options (including its BLQ and infusion options where they exist; where PKNCA has no equivalent, compute the expected value in the testkit's naive implementation and say so), add them as oracle cases with `.options.json`, extend `crates/caladrius-nca/tests/oracle_synthetic.rs` (or a new `oracle_edge.rs`), and extend `cargo xtask conformance` coverage automatically (it reads `oracle/expected/*`; check that new cases appear and floors are created).

## Allowed files

`oracle/`, `crates/caladrius-testkit/`, `crates/caladrius-nca/tests/`, `ATTRIBUTION.md` (append), `board/QUESTIONS.md` (append).

## Completion criterion

Scripts regenerate byte-identically; `cargo test -p caladrius-testkit` ok; `cargo test -p caladrius-nca` result reported honestly (new tests may fail: that is information for the engine, do not touch `src/`); `cargo xtask conformance` output reported.

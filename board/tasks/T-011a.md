# T-011a: caladrius-fit core: weighted least squares, Gauss-Newton with Levenberg and Hartley modification

- **Role:** engine
- **State:** to review
- **Depends on:** T-010

## Goal

The core of `caladrius-fit` against the 114 oracle tests' API (header of `crates/caladrius-fit/tests/oracle_fit.rs`: `FitInput`, `FitOptions` with the defaults of `AGENTS.md` section 6, `Weighting`, `FitStatus`, `FitResult { status(), get(name), trace() }`, `run`): a model trait implemented by `caladrius-models`, weights 1, 1/y, 1/y², 1/ŷ, 1/ŷ² (predicted-value weights recomputed at each iteration per `specs/fit.md`), Gauss-Newton with the Levenberg and Hartley modification as default, convergence criterion, max iterations, forward-difference derivatives with relative increment, final estimates, standard errors, CV%, WRSS, residual SS, S, DF, AIC, SBC, predicted values; the status distinguishes converged / max iterations / no fixed point (cases listed in the oracle as `no_fixed_point` must not report convergence). Tolerances: parameters 1e-4 relative, WRSS 1e-6 relative (`AGENTS.md` section 5).

## Allowed files

`crates/caladrius-fit/src/`, `crates/caladrius-fit/Cargo.toml`, `specs/differences.md` (append).

## Completion criterion

```sh
cargo test -p caladrius-fit --no-fail-fast     # estimates/SE/CV%/WRSS/AIC groups green on all fit cases; CI/matrix/trace groups may remain for T-011b
cargo clippy -p caladrius-fit --all-targets -- -D warnings
cargo xtask layers
```

Then `reviewer` approval.

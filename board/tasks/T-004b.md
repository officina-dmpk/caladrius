# T-004b: caladrius-nca: λz selection, t½, extrapolation

- **Role:** engine
- **State:** to review
- **Depends on:** T-004a

## Goal

Terminal phase: automatic λz point selection (best adjusted R² with the rules in `specs/nca.md`: minimum number of points, exclusion of Cmax and of the back-extrapolated C0 point, `adj_r_squared_factor`, user override), λz, its R² and adjusted R², number of points and time span used, t½, Clast predicted, AUCinf (observed and predicted), AUMCinf, %AUC extrapolated, with readable errors when λz is not estimable (fewer points than the minimum, non-decreasing terminal phase).

## Allowed files

`crates/caladrius-nca/src/`, `crates/caladrius-nca/Cargo.toml`, `specs/differences.md` (append only, if a documented method difference appears).

## Specification

Follow `specs/nca.md`. The oracle's `.options.json` files state the PKNCA options used; the oracle thread in `board/tasks/T-003.md` records that PKNCA keeps λz even when the adjusted R² is below `min.hl.r.squared` (Indometh subject 4: R² 0.867). Match the oracle; if a rule of `specs/nca.md` disagrees with the oracle, document it in `specs/differences.md` rather than loosening a tolerance.

## Completion criterion

```sh
cargo test -p caladrius-nca                                   # λz, t½, AUCinf, AUMCinf, %extrapolated green on all 4 oracle cases
cargo clippy -p caladrius-nca --all-targets -- -D warnings    # ok
```

Then `reviewer` approval.

# T-033: caladrius-models two-compartment models (pk2.*), derivatives, and xtask conformance for pk2

- **Role:** engine
- **State:** in progress
- **Depends on:** T-032

## Goal

Make the T-032 oracle green: `crates/caladrius-models/tests/oracle_models_2c.rs` (508 tests: 428 value, 64 derivative, 6 error-group, 9 property, 1 guard) against `oracle/expected/models/pk2/` (107 value cases, 11,145 values at `MODEL_VALUES` 1e-12 relative with the absolute tail floor; 64 derivative cases, 5,595 values at `MODEL_DERIVATIVES` 1e-12; 80 error cases), following `specs/models.md` section 11 (MOD-2C-01..24) and the orchestrator's decisions in the T-032 thread.

1. `caladrius-models`: ids `pk2.iv_bolus`, `pk2.iv_infusion`, `pk2.oral_1`, `pk2.oral_1_lag`, `pk2.oral_0`, `pk2.oral_0_lag`; default parameterisation (cl, vc, q, vp) with the conversions to and from the two others (MOD-2C-02/03, domains and errors per MOD-GEN-04); concentrations as positive sums of two one-compartment kernels (MOD-2C-06..), stable near ka = α, ka = β and α ≈ β (sum-of-non-negative-terms discriminant, MOD-2C-03), the limit forms, overflow handling (MOD-NUM-01); derived quantities (half-lives, AUC, AUMC(0,t) and (0,∞), MRT, Vss, Vz, Cmax/Tmax with the bracketed bisection of MOD-2C-xx for oral), outputs named as the oracle expects (`w_alpha`, `w_beta`, `a_oral`, `b_oral`, `aumc[i]`...). Partial derivatives w.r.t. (cl, vc, q, vp) through ψ = (V, α, β, w) with the chain rule (MOD-2C-19..), so that `caladrius-fit` can use `Derivatives::Analytic` on pk2 (wire the closed forms in `caladrius-fit/src/closed_forms.rs` too if the routing is by model id; otherwise leave a note).
2. If a derivative value cannot reach 1e-12 in double precision on a well-conditioned entry, do NOT loosen: record the entry, the achieved error and the reason in the card and set the test aside with a `documented_differences` marker through the oracle agent (write a message in `board/messages/`), never by editing the expected file.
3. `xtask/src/conformance/step3.rs`: list the `pk2/` subdirectory, report an unknown id as an error line at 0 validated instead of aborting, map the new quantities (`aumc[i]`, derivatives, error suite), relax the "conc, auc first" guard to include aumc, keep the floors monotone; `cargo test -p xtask` green; `cargo xtask conformance` regenerated and committed.
4. Catalogue: `caladrius-engine` model list and schemas, `caladrius-ui` `modelinfo.rs` catalogue only if a build breaks without it (the UI page for pk2 is a later interface card; say what is missing).

## Allowed files

`crates/caladrius-models/src/`, `crates/caladrius-fit/src/closed_forms.rs` and its routing, `xtask/`, `docs/conformance.md` (regenerated), `crates/caladrius-engine/src/` (catalogue entries only), the card, `board/messages/`. Not `oracle/`, not `caladrius-testkit`, not the oracle test files, not `specs/`.

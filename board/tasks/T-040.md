## Goal

3. Measurement: a test (or the existing `--ignored` report of T-029) showing the new default against the 185 reference fits: 0 of 490 estimates beyond 1e-4, worst gap reported in the card. The oracle tests themselves are unchanged (they set their options explicitly).
4. `specs/fit.md`: FIT-JAC-01 and FIT-CNV-01 default values updated, status `assumed` (the new defaults are a Caladrius choice: say so); D-03 marked as settled by Q-014 option 2 with the measurement; new D-04 "default settings differ from the assumed reference defaults, which remain the `reference_conventions` preset". Write these short factual spec lines yourself (the decision is taken); keep the spec's status vocabulary.
5. Engine and UI exposure: `caladrius-engine` schema for the preset (one short enum; MCP tools/list growth under 200 bytes), and the fit page "More options" shows the preset choice with one sentence.

# T-034: pk2 reachable from the engine, CLI and MCP (a), then the UI (b)

- **Role:** interface
- **State:** in progress
- **Depends on:** T-033

## Goal

T-033 put the six `pk2.*` models in `caladrius-models` and their analytic derivatives in `caladrius-fit`, but the engine schemas and the UI catalogue list only `pk1` ids, so `model.simulate`, `fit.run`, `fit.evaluate` and the model commands reject `pk2.*` (T-033 thread, item 7).

**T-034a (this card first):** `caladrius-engine` command schemas and model catalogue accept every `pk2.*` id with the three parameter sets of MOD-2C-02 (names from the spec and the oracle: cl, vc, q, vp; micro and macro sets), `fit.initial_estimates` returns the readable "not available for pk2, supply them" refusal through the command (not an error 500), `fit.run`/`fit.evaluate`/`model.simulate` work end to end on a pk2 dataset (engine tests with a simulated pk2 profile from `oracle/expected/models/pk2/` inputs, public), `caladrius-cli` and `caladrius-mcp` expose them without change beyond the schemas (tests that a pk2 fit runs over MCP and the CLI). Schemas stay small (the MCP tool list is sent to a 12k-context model: the `fit_run` schema must not grow by more than a few hundred bytes; put the parameter sets in a short enum with a one-line description).

**T-034b (later, after the Apothicaire benchmark per the validated order):** UI: model picked by route, compartments and parameter set with the two-compartment diagram and equation in `modelinfo.rs`, labels and units, fit page and simulation page accepting pk2, palette entries, snapshots.

## Allowed files

(a) `crates/caladrius-engine/`, `apps/caladrius-cli/`, `apps/caladrius-mcp/`, `README.md` (CLI/MCP lines only), the card. Not the numerical crates, not `caladrius-ui` (b).

## Completion criterion (a)

```sh
cargo test -p caladrius-engine -p caladrius-cli -p caladrius-mcp
cargo clippy -p caladrius-engine -p caladrius-cli -p caladrius-mcp --all-targets -- -D warnings
cargo xtask layers && cargo xtask wasm
```

`python ../agent/apothicaire.py tools` (optional, if the MCP binary is rebuilt) still shows a static prefix under 2.5k tokens, or the card says by how much the schema grew. Reviewer not required for (a) (no numerical code); the orchestrator reads the diff.

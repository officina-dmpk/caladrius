# T-005: Synthetic oracle profiles to settle λz open items O-01 and O-02

- **Role:** oracle
- **State:** to review
- **Depends on:** T-003

## Goal

`specs/nca.md` leaves two λz rules ambiguous because the public profiles do not discriminate between readings: O-01 (PKNCA's tie rule when several candidate point sets share the best adjusted R²) and O-02 (the order of the positive-slope filter relative to the selection). Build small synthetic profiles that discriminate (start from worked example W6 / profile D1 in `specs/nca.md`), run PKNCA on them with the same explicit options as T-003, add them as oracle cases, and extend the oracle tests.

## Allowed files

`oracle/data/synthetic_*.csv`, `oracle/data/README.md` (append), `oracle/scripts/` (new script or an extension of `nca_pknca.R` that keeps the existing outputs byte-identical), `oracle/expected/synthetic_*`, `crates/caladrius-testkit/` (loaders if needed), `crates/caladrius-nca/tests/oracle_synthetic.rs` (new file), `board/QUESTIONS.md` (append only).

## Completion criterion

```sh
Rscript oracle/scripts/nca_pknca.R      # existing expected files unchanged, synthetic cases generated
cargo test -p caladrius-testkit         # ok
```

Report, for O-01 and O-02, which reading PKNCA follows, with the profile and numbers that prove it, so that the orchestrator can have the spec tags updated.
